About RAILSETU

A large educational railway-booking interface built with web fundamentals.

Our idea

RAILSETU demonstrates how HTML5, CSS3 and Vanilla JavaScript can create a complete multi-page travel booking experience without React, Bootstrap or Tailwind.

What it demonstrates

Search, filtering, passenger forms, interactive seats, simulated payments, PNR lookup, booking history and ticket generation using browser storage.

Important

This is an educational demo and is not connected to Indian Railways or IRCTC. No real money is charged and no real reservation is created.
