
# 🚆 RAILSETU — Indian Railway Booking Website

A large multi-page railway booking website created using **HTML5 + CSS3 + Vanilla JavaScript**.

> **Educational project:** This project is a front-end simulation. It is NOT connected to Indian Railways/IRCTC and does not create real reservations or charge real money.

## ✨ Features

- Modern railway-themed responsive UI
- Animated CSS train hero graphic
- Station search
- Train search and route filtering
- Train details
- Passenger management
- Interactive seat selection
- Simulated payment
- Automatic PNR generation
- Digital ticket
- Print ticket
- Booking history
- Ticket cancellation
- Refund simulation
- PNR status lookup
- Train running-status demo
- Station directory
- Login/register simulation
- Browser `localStorage` persistence
- Mobile responsive navigation
- Toast notifications
- No React / Vue / Angular / Bootstrap / Tailwind

## ▶️ How to run

1. Extract the ZIP.
2. Open the `RAILSETU` folder.
3. Double-click `index.html`.
4. Select a From and To station.
5. Search a train.
6. Select a train.
7. Add passenger details.
8. Select a seat.
9. Select a demo payment method.
10. Generate your digital ticket.

For the best development experience, open the folder in VS Code and use a local server such as Live Server.

## 🔄 Booking flow

`Home → Search → Train Details → Passengers → Seat Selection → Payment → Digital Ticket`

All demo booking information is stored in the browser using `localStorage`.
